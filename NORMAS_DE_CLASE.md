# Normas de clase y laboratorio

## Trabajo académico

- Las actividades se desarrollan con puntualidad y participación.
- El trabajo grupal no elimina la responsabilidad individual.
- Cada estudiante debe poder explicar conexiones, código y resultados.
- Las fuentes, librerías y repositorios consultados deben citarse.
- No se acepta código copiado que el estudiante no pueda analizar.

## Seguridad eléctrica

- Verificar tensión y polaridad antes de energizar.
- Desenergizar antes de modificar el montaje.
- Mantener tierras comunes únicamente cuando la arquitectura lo requiera.
- Usar conversores de nivel cuando las tensiones lógicas sean incompatibles.
- No alimentar motores, relés o cargas inductivas desde GPIO.
- Usar diodos, transistores, drivers, optoacopladores o módulos adecuados.
- No conectar montajes estudiantiles directamente a 120 V.

## ESP32 y Raspberry Pi

- Ambos trabajan con lógica de 3,3 V.
- Los GPIO de la Raspberry Pi no toleran entradas de 5 V.
- Revisar el pinout antes de conectar.
- Apagar correctamente la Raspberry Pi antes de retirar energía.
- Mantener copia de seguridad del proyecto y configuración.

## Gestión de archivos

- Usar nombres claros y versiones identificables.
- No subir contraseñas, tokens o datos privados al repositorio.
- Separar configuración sensible del código.
- Entregar evidencias en el formato indicado en Teams.

## Integridad académica

Se pueden utilizar herramientas digitales para consultar, organizar y depurar. La entrega debe reflejar comprensión propia y cada integrante debe defender las decisiones técnicas tomadas.
