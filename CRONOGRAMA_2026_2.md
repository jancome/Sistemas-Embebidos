# Cronograma general – Periodo 2026-2

La programación sigue los contenidos numerados del syllabus aprobado y utiliza el mismo calendario académico establecido.

## Plataformas por corte

| Corte | Plataforma principal |
|---|---|
| Corte 1 | EasyEDA |
| Corte 2 | ESP32 |
| Corte 3 | Raspberry Pi 4 |

EasyEDA se utilizará en el primer corte para diseñar la placa base del nodo ESP32. En el segundo corte se desarrollará el firmware y las comunicaciones sobre ESP32. En el tercer corte se integrará el ESP32 con una Raspberry Pi 4 como computador de borde.

## Semana de receso

Durante la semana del **5 al 11 de octubre de 2026** no se programará contenido nuevo.

## Herramientas complementarias

- Arduino IDE o Visual Studio Code para ESP32.
- Wokwi para simulaciones preliminares.
- Raspberry Pi Imager para preparar Raspberry Pi OS.
- Python y SQLite para la capa de alto nivel.
- Cliente SSH para administración remota.
