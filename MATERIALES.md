# Materiales y herramientas del curso

## Hardware por grupo

### Unidad 1 y Unidad 2

- Kit de desarrollo con microcontrolador; ESP32 como referencia principal.
- Cable USB de datos compatible.
- Protoboard y cables de conexión.
- Multímetro.
- Resistencias, capacitores, LED y componentes semiconductores.
- Sensor o sensores del proyecto.
- Actuador o indicador con su etapa electrónica.
- Periférico SPI.
- Display LCD con módulo I2C, servomotor o relé cuando la práctica lo requiera.
- Fuente DC regulada.

### Unidad 3

- Raspberry Pi 4 como SBC seleccionado.
- Fuente adecuada para la Raspberry Pi.
- Tarjeta microSD.
- Acceso a red.
- Módulo USB–UART de 3,3 V cuando sea necesario.
- Conversor de nivel lógico cuando corresponda.
- Elementos para prácticas GPIO.

## Equipos de laboratorio

- Multímetro.
- Analizador lógico.
- Osciloscopio.
- Fuente de alimentación DC.
- Generador de frecuencia cuando sea necesario.
- Herramientas mecánicas y eléctricas: pinzas, alicates, cutters y destornilladores.

## Software aprobado o compatible con el syllabus

- EasyEDA, KiCad, Proteus o Altium para diseño EDA.
- Visual Studio Code u otro IDE compatible con la plataforma elegida.
- Toolchain correspondiente al microcontrolador.
- Raspberry Pi OS basado en Linux.
- Lenguaje de alto nivel y bibliotecas para GPIO, comunicación, base de datos y dashboard.
- Cliente SSH.

## Herramientas complementarias

- Arduino IDE, PlatformIO o ESP-IDF cuando se utilice ESP32.
- Wokwi como simulador complementario, sin reemplazar las pruebas físicas.
- Python y SQLite como implementaciones propuestas para la Unidad 3.
