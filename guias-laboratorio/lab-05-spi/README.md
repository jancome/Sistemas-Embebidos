# Lab 05 – Comunicación SPI

## Propósito

Integrar y verificar un periférico SPI.

## Procedimiento

1. Identificar pines y tensión lógica.
2. Definir modo SPI y frecuencia.
3. Conectar CS, SCLK, MOSI, MISO y GND.
4. Ejecutar una lectura o escritura.
5. Registrar la transacción.
6. Cambiar una condición para provocar un error.

## Evidencia

Diagrama, configuración, captura del analizador lógico o monitor serial, comando, respuesta y diagnóstico de error.
