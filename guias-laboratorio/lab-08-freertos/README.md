# Lab 08 – FreeRTOS

## Propósito

Organizar adquisición, control y comunicación en tareas concurrentes.

## Procedimiento

1. Crear tareas de sensor, control, comunicación y registro.
2. Definir periodos y prioridades.
3. Crear una cola para mediciones.
4. Evitar retardos bloqueantes.
5. Probar llenado o vaciado de cola.
6. Registrar tiempos y memoria.
7. Analizar una posible condición de carrera.

## Evidencia

Diagrama de tareas, tabla de periodos, código, registros temporales, uso de cola y conclusión sobre concurrencia.
