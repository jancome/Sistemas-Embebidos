# Lab 09 – Raspberry Pi 4: Linux, SSH, Python y GPIO

## Propósito

Configurar la Raspberry Pi como computador de borde y verificar un GPIO seguro.

## Procedimiento

1. Preparar Raspberry Pi OS.
2. Configurar red y SSH.
3. Acceder remotamente.
4. Crear entorno virtual de Python.
5. Identificar pinout BCM.
6. Conectar LED con resistencia y pulsador o sensor digital.
7. Ejecutar la prueba con GPIO Zero.

## Seguridad

No aplicar 5 V a un GPIO. No conectar motores o relés directamente.

## Evidencia

Captura SSH, comandos, entorno virtual, diagrama de conexión, código y resultado.
