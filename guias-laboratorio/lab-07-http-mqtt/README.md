# Lab 07 – HTTP o MQTT

## Propósito

Enviar datos del ESP32 mediante un protocolo de aplicación.

## Procedimiento

1. Definir destino, método o tópico.
2. Diseñar el payload.
3. Enviar una medición.
4. Registrar código o confirmación.
5. Medir tiempo de comunicación.
6. Probar servicio no disponible.
7. Aplicar timeout y reintento controlado.

## Evidencia

Diagrama, payload, respuesta, tiempos, consumo aproximado de recursos y comportamiento ante falla.
