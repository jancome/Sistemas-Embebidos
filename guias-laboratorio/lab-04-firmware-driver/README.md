# Lab 04 – Firmware modular y driver

## Propósito

Implementar un driver a partir de datasheet dentro de una arquitectura por capas.

## Procedimiento

1. Identificar registros, comandos o secuencia de operación.
2. Definir interfaz pública del driver.
3. Implementar inicialización, lectura y manejo de error.
4. Separar driver y lógica de aplicación.
5. Probar con condiciones normales y una falla provocada.

## Evidencia

Código organizado, sección del datasheet utilizada, prueba, resultado y explicación de cada función pública.
