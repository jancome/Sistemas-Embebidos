# Lab 01 – Requerimientos y arquitectura

## Propósito

Transformar una necesidad real en una arquitectura verificable de sistema embebido.

## Procedimiento

1. Definir usuario y contexto.
2. Identificar variable física.
3. Establecer rango, precisión y frecuencia.
4. Definir salida o actuador.
5. Separar responsabilidades ESP32 y Raspberry Pi.
6. Dibujar el diagrama de bloques.
7. Escribir criterios de aceptación.

## Evidencia

Matriz de requerimientos, diagrama de bloques, selección preliminar y tres pruebas que deberán realizarse al final del proyecto.
