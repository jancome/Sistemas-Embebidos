# Lab 03 – Esquemático, PCB y fabricación

## Propósito

Crear la documentación necesaria para fabricar la placa base.

## Procedimiento

1. Organizar el esquemático por bloques.
2. Verificar símbolos y footprints.
3. Ejecutar ERC.
4. Ubicar componentes con criterio funcional.
5. Rutear señales y alimentación.
6. Crear plano de tierra.
7. Ejecutar DRC.
8. Revisar vista 3D.
9. Generar Gerber, taladros y BOM.
10. Obtener cotización.

## Evidencia

PDF del esquemático, capturas 2D/3D, reporte DRC, ZIP Gerber, BOM y cotización.
