# Código de ejemplo

Esta carpeta alojará ejemplos docentes mínimos y separados por propósito:

- ESP32: GPIO y lectura de sensores.
- Drivers propios.
- SPI.
- Wi-Fi y Bluetooth/BLE.
- HTTP y MQTT.
- FreeRTOS.
- Raspberry Pi: GPIO Zero.
- UART y validación de tramas.
- SQLite.
- Dashboard.
- Servicio y logs.

Los ejemplos deben ser pequeños, verificables y acompañados de una explicación. El código completo de cada grupo se entregará mediante el mecanismo definido en Teams.
