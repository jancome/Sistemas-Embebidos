# Guía rápida para estudiantes

## Qué construiremos

Un sistema embebido distribuido con dos niveles:

- **ESP32:** adquisición, control y tareas de tiempo real.
- **Raspberry Pi 4:** procesamiento, almacenamiento, visualización y operación sobre Linux.

## Cómo trabajaremos

- Grupos de 3 estudiantes.
- Una evidencia técnica por semana.
- Tres fases acumulativas con retroalimentación.
- Sustentaciones individuales dentro del trabajo grupal.
- GitHub para recursos permanentes.
- Teams para tareas, entregas, rúbricas y notas.

## Qué debes llevar al laboratorio

- Computador con entorno instalado.
- ESP32 y cable USB de datos.
- Protoboard, cables y componentes asignados.
- Multímetro.
- Bitácora o registro digital.
- Archivos actualizados del proyecto.

En el tercer corte el grupo también debe contar con Raspberry Pi 4, fuente adecuada, microSD y acceso a red local.

## Evidencia semanal

Cada práctica debe registrar:

1. Objetivo.
2. Diagrama o conexión.
3. Procedimiento.
4. Código o configuración.
5. Medición o resultado.
6. Error encontrado.
7. Corrección aplicada.
8. Conclusión técnica.

## Regla principal

No se evalúa únicamente que el sistema encienda. Se evalúa que el estudiante pueda explicar por qué funciona, cómo se midió y qué ocurriría ante una falla.
