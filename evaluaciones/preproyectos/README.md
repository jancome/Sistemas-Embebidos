# Preproyectos y fases ABP

## Preproyecto 1 – Arquitectura y placa base

Debe demostrar que el proyecto es electrónicamente viable antes de programarlo.

Incluye:

- problema y usuarios;
- requerimientos;
- arquitectura;
- sensor y actuador;
- alimentación y protecciones;
- esquemático;
- PCB y DRC;
- Gerber;
- BOM y cotización;
- sustentación.

## Preproyecto 2 – Firmware y comunicaciones

Debe demostrar que el nodo ESP32 puede adquirir, controlar y comunicar datos de forma modular y no bloqueante.

Incluye:

- firmware por capas;
- driver basado en datasheet;
- SPI;
- Wi-Fi o Bluetooth/BLE;
- HTTP o MQTT;
- tareas FreeRTOS;
- cola o mecanismo de sincronización;
- pruebas y manejo de errores;
- sustentación.

## Proyecto final

Integra ESP32 y Raspberry Pi 4 con procesamiento, SQLite, dashboard, servicio, logs y recuperación ante fallas.

Los avances pueden corregirse con la retroalimentación recibida. La versión final se evalúa por su estado definitivo y por el dominio individual del sistema.
