# Semana 01 – Inicio, diagnóstico y arquitectura distribuida

**Fecha:** 5 de agosto de 2026 · **Fase 1**

**Material de estudio:** [Marco teórico ampliado](marco-teorico.md)

## Pregunta guía

¿En qué se diferencia un sistema embebido de un computador general y qué problema real puede resolver un nodo ESP32 integrado con una Raspberry Pi 4?

## Resultados

- Reconocer la estructura de la asignatura y del proyecto ABP.
- Diferenciar sensor, acondicionamiento, microcontrolador, actuador y SBC.
- Formular una necesidad concreta de ingeniería electrónica.
- Proponer una arquitectura inicial verificable.

## Contenidos

- Concepto de sistema embebido.
- Microcontrolador, SoC y SBC.
- Ciclo entrada–procesamiento–salida.
- ESP32 como nodo de tiempo real.
- Raspberry Pi 4 como computador de borde.
- Requerimientos funcionales y no funcionales.

## Actividad de clase

1. Diagnóstico individual.
2. Formación de grupos de 3.
3. Selección de una necesidad del contexto.
4. Identificación de variable física, sensor, salida y usuario.
5. Diagrama de bloques preliminar.

## Evidencia ABP

- Grupo conformado.
- Situación específica.
- Variable de entrada y salida esperada.
- Diagrama de bloques ESP32–Raspberry Pi.
- Riesgos o dudas técnicas iniciales.
