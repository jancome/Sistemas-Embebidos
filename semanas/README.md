## Progresión tecnológica

```text
CORTE 1 – EasyEDA
Arquitectura electrónica, esquemático, PCB, DRC, Gerber y BOM
        ↓
CORTE 2 – ESP32
Firmware modular, drivers, SPI, conectividad y FreeRTOS
        ↓
CORTE 3 – Raspberry Pi 4
Linux, Python, comunicación, SQLite, dashboard y robustez
```

Cada marco teórico contiene fundamentos, criterios de diseño, ejemplos guiados, actividades prácticas, conexión con el proyecto ABP, diagnóstico de fallas, errores comunes, trabajo independiente y referencias de apoyo.
