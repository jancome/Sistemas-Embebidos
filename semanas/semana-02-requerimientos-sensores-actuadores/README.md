## Pregunta guía

¿Cómo seleccionar sensores y actuadores a partir de requisitos medibles y no por disponibilidad o preferencia?

## Resultados

- Convertir una necesidad en requerimientos verificables.
- Consultar rango, precisión, resolución, interfaz y alimentación de sensores.
- Identificar la etapa necesaria para controlar un actuador.

## Contenidos

- Requerimientos funcionales y no funcionales.
- Rango, resolución, exactitud y frecuencia de muestreo.
- Sensores analógicos y digitales.
- Actuadores, indicadores y etapas de potencia.
- Interfaces ADC, GPIO, I2C, SPI y UART.

## Laboratorio / taller

Construir una matriz de selección con mínimo tres alternativas de sensor y dos de actuador. Comparar tensión, corriente, interfaz, costo, disponibilidad, riesgo y compatibilidad con ESP32.
