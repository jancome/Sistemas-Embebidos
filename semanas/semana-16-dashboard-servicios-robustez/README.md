# Semana 16 – Dashboard, servicios, logs y robustez

**Fecha:** 18 de noviembre de 2026 · **Fase 3**

## Pregunta guía

¿Cómo lograr que el sistema opere después de reinicios y permita diagnosticar una falla sin ejecutar manualmente cada programa?

## Resultados

- Construir una visualización local.
- Ejecutar la aplicación como servicio.
- Registrar eventos y errores.
- Probar reinicio y reconexión.

## Contenidos

- Dashboard o interfaz web.
- Separación entre datos y presentación.
- Servicio `systemd`.
- Inicio automático y reinicio del proceso.
- Logs con niveles y timestamps.
- Reconexión serial o de red.
- Pruebas de recuperación.

## Laboratorio

Crear una vista de estado e históricos, configurar el servicio, reiniciar la Raspberry Pi y demostrar que la aplicación vuelve a operar y registrar datos.

## Evaluación

- Quiz 3.
- Servicio habilitado.
- Evidencia de logs.
- Prueba de recuperación.
